# 📊 Pandalytics — A Fun Pandas + Plotly Project

This is a simple Python project that shows how to play with data using **pandas** (a tool for working with tables, like Excel) and draw pretty pictures using **Plotly** (a tool for making graphs).

## 🤔 What Does This Project Do?

Think of it like a small notebook with **5 people's information** (name, city, age, phone number). The script does lots of small tasks on this data — one by one — so you can see exactly what each pandas trick does.

## 📚 What You Will Learn

- How to make a table (like Excel) using code
- How to look at the table (first rows, last rows, total rows)
- How to pick out one column or one row
- How to find only the rows you want (like "show me people older than 26")
- How to add a new column
- How to remove a column or row
- How to fix empty/missing boxes in the table
- How to sort the table (smallest to biggest)
- How to group similar rows together
- How to join two tables into one
- How to work with text (names, words)
- How to work with dates
- How to find totals, averages, and other simple math facts
- How to save the table as a file (CSV or Excel)
- How to draw graphs (bar chart, pie chart, dots, and lines) from the data

## 🎨 The Pictures (Graphs) It Makes

- A **bar chart** — tall bars showing each person's age
- A **pie chart** — a pizza-slice picture showing ages by city
- A **scatter plot** — dots showing each person
- A **line chart** — a line connecting the ages
- A **dashboard** — all four pictures together on one page

## 🧰 What You Need Before Running It

Open your computer's terminal and type this once:

```bash
pip install pandas numpy plotly openpyxl
```

## ▶️ How to Run It

Type this in the terminal:

```bash
python pandas_demo.py
```

## 📦 What You Get After Running

- The steps and results printed on your screen
- A CSV file (like a simple Excel file) with the data
- An Excel file with the data
- An HTML file with all the graphs — just open it in your browser like a webpage!

## 🙋 Who Is This For?

Anyone! Even if you have never used pandas before. Every single line of code has a simple comment next to it explaining what it does — like a friend explaining it in easy words.
